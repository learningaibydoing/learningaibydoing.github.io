# Learning AI by Doing

A single-page, static website introducing four participatory machine-learning exercises. The page is designed for GitHub Pages and has no build step.

## Preview locally

Open `index.html` directly or serve this directory with any static web server.

## Add the interactive exercises

Each exercise ends with a `.embed-slot` button that currently reveals “Content in development.” Replace the matching button with the supplied interactive code or an accessible `iframe`. Keep a descriptive `title` on every iframe and preserve a visible fallback link when the embed depends on another service.

## Deploy

GitHub Pages can publish directly from the repository root on the default branch.
